Latent Demand Recovery and Forecasting on FreshRetailNet-50K
The methodology consists of two stages. First, latent demand obscured by stockouts is recovered from the recorded sales data. Second, the recovered demand is used for 7-day-ahead forecasting. Each forecasting model is run under two conditions: using the original recorded sales (raw) and using the recovered demand (recovered), enabling a direct comparison of forecasting performance.
Dataset: FreshRetailNet-50K, 50,000 store-product series over 90 days.

Inputs
All input files are stored in inputs/.
Download freshretailnet_train.parquet and freshretailnet_test.parquet from the dataset release and place them in this directory.
recovered_demand_timesnet.parquet contains the training data with the recovered demand column added. daily_demand.parquet is generated by src/data.py and is the final dataset read by the forecasting models.

Notebook workflow
Start with 01_data_loading.ipynb to build the model input. Next, run 02_timesnet_demand_recovery.ipynb for the demand recovery stage. This notebook has already been run, and its output is saved for the subsequent steps.
03_EDA.ipynb is optional and can be used for data exploration.
The forecasting models are grouped by model family and can be run in any order:
•	04.statsmodel.ipynb — SeasonalNaive, CrostonSBA
•	05.MLmodel.ipynb — LightGBM
•	06.neuralforecast.ipynb — DLinear, LSTM, Informer, PatchTST, TiDE, TFT
•	07.Foundationmodels.ipynb - TimesFM
• 08. Chronos.ipynb - Chronos-2
•	13.TFTBaseline.ipynb — the TFT implementation from the original paper
•	09.Router.ipynb 
After running the forecasting models, finish with Router.ipynb. The router learns which series should use the raw or recovered forecast.
Finally, run 11.EvaluationCharts.ipynb to generate the final evaluation tables and figures.

Other folders
•	src/ — shared configuration, data loading, prediction saving, and scoring code.
•	Latent Demand Recovery/ — reference implementation from the paper authors (PyPOTS / TimesNet), reused as-is for Stage 1.
•	predictions/val/ — validation-set model predictions.
•	predictions/test/ — test-set model predictions.
•	evaluation/ — evaluation results and summary tables.
•	figures/ — generated charts and figures.

Setup
Set PROJECT in src/config.py to the local path of the project.
Then, at the top of each notebook, add:
import sys
sys.path.append(f'{PROJECT}/src')
import config as cfg
cfg.check()
Run cfg.check() to verify that the project paths and configuration are set correctly before running the notebook.
